# 05 · Quarterly Results (124 BPM)

**Suno → https://suno.com/create → pestaña `Advanced` → `Instrumental` activado → Lyrics vacío.**

(Plan Pro o Premier: el plan gratuito no da uso comercial.)

Pega esto en **Styles**:

```
dark techno with orchestral strings, 124 BPM, steady 4/4, four-on-the-floor kick, rimshot on 2 and 4, rolling bassline, no tempo changes, beat starts immediately, no fade-in, builds after 30 seconds and peaks at 45 seconds, sleek, corporate, cold steel.
```

Título (opcional, solo etiqueta interna; si no hay campo, ignóralo):

```
Quarterly Results
```

Genera, escucha las dos tomas y quédate con la de bombo más regular y sin intro larga.

Guarda el mp3 como:

```
audio-src/aura-inbox/executive-rumble-124.mp3
```

Cuando tengas varias: `npm run aura:tracks`.
